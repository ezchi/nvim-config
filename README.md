# nvim-config

Neovim config.

## Migrating from Emacs

This config is being built out as a replacement for `~/.emacs.d`.
**[docs/migration-plan.md](docs/migration-plan.md) is the single source of truth** for that
migration: current status, locked decisions, the shared Emacs/Neovim keymap contract, and
the per-phase checklists. Read §0 of that file before picking up any migration work.
